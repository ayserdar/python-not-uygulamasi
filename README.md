# Worldscirpt AI YKS Asistanı

YKS için geliştirilmiş AI destekli takip ve analiz uygulaması.

## Özellikler
- Ders, doğru, yanlış girişi
- Net hesaplama
- Kayıt ekleme ve silme
- Analiz paneli
- Günlük çalışma önerisi

## Amaç
Öğrencinin eksik derslerini görmesini ve daha verimli çalışmasını sağlamak.

## Teknolojiler
- Python
- Tkinter
- JSON
